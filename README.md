# prelum.github.io

The site of [prelum](https://github.com/prelum/prelum): Markdown in. Beautiful PDF out.

Static HTML and CSS, no build step. English at the root, Portuguese in `pt/`. Fonts are self-hosted (OFL) and the page previews come from `npm run examples` in the main repository. The motion uses [GSAP](https://gsap.com) with ScrollTrigger, self-hosted in `vendor/`. Without it, or with reduced motion on, the page is static.

To preview locally, open `index.html` in a browser.
